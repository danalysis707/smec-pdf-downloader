▶ クイズを開始する

クイズアプリの使い方

1 科目・テーマ・年度を選ぶ

トップ画面で学習したい科目を選択します。

  • 科目（必須） — 7科目から1つ選択
  • テーマ（任意） — 科目内のテーマを複数選択可。未選択で全テーマ
  • 年度（任意） — 令和2〜7年度を複数選択可。未選択で全年度

対象問題数が「▶ 学習開始（N問）」に表示されたら開始できます。

2 問題に解答する

問題画像が表示されます。ア〜オのボタンをタップして解答してください。

  • 画面上部に年度・科目・問番号が表示されます
  • 「🔍 この問題を検索して解説を見る」でGoogle検索へ飛べます
  • ピンチ操作で画像を拡大できます

3 正誤を確認する

解答すると結果が表示されます。

  • 正解・あなたの解答を表示
  • 「🔍 解説をネット検索」で該当問題の解説ページを検索
  • YouTube関連動画があれば自動表示（要設定）
  • 📝 メモ欄に気づきを記録できます（端末に自動保存）

4 次の問題へ / 完了

「次の問題へ →」で次へ進みます。全問終了すると正答率が表示されます。

  • 「もう一度」— 同じ問題セットをシャッフルして再挑戦
  • 「科目選択に戻る」— フィルター画面に戻る
メモは自動保存: 同じ問題を次回開いたときに復元されます（ブラウザのlocalStorageに保存）。

YouTube関連動画を表示する（オプション）

1 yt-dlp をインストールする

pip install yt-dlp

2 fetch_youtube.py を実行する

対応チャンネルから動画タイトルを取得し、テーマごとに分類します。

python fetch_youtube.py

完了すると docs/data/youtube_data.json が生成されます。

対応チャンネル（youtube_config.json で設定）:

  • はじめよう経済学
  • ほらっちチャンネル
  • たかぴーの中小企業診断士試験 攻略チャンネル

3 デプロイする

git add docs/data/youtube_data.json
git commit -m "feat: add youtube data"
git push origin master
数分後にクイズアプリの解答画面にYouTube関連動画リンクが表示されます。

データ更新・再ビルド（開発者向け）

0 必要なもの

ソフトウェア確認コマンド推奨バージョン
Pythonpython --version3.8 以上
Gitgit --version任意

1 リポジトリをクローンする

git clone https://github.com/danalysis707/smec-pdf-downloader.git
cd smec-pdf-downloader

2 ライブラリをインストールする

pip install -r requirements.txt

インストールされるライブラリ:

  • requests — PDF ダウンロード
  • PyMuPDF — PDF→JPEG 変換
  • pdfplumber — テキスト抽出・解答検出
  • pytest — テスト実行

3 PDFをダウンロードする

python download.py

downloads/ に年度別・科目別で保存されます（問題・解答の合計84ファイル）。

再実行は安全: 既存ファイルはスキップされます。

4 クイズデータ・画像を生成する

python build.py

以下のファイルが生成されます:

docs/
├── data/
│   ├── quiz_data.json  ← 問題メタデータ（1,199問）
│   └── theme_map.json  ← テーマ・キーワード定義
└── images/
     ├── r02/keizai/page_001.jpg
     ├── r02/keizai_answer/page_001.jpg
     └── …（1,330枚）
再実行は安全: 既存の画像ファイルはスキップされます。

5 デプロイする

git add docs/
git commit -m "feat: update quiz data"
git push origin master
GitHub Pages（master ブランチの /docs）に自動反映されます。

6 テストを実行する（任意）

pytest tests/ -v
12 passed in X.XXs
