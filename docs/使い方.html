実行手順書

全7科目 令和2〜7年度 問題・解答PDF

0 必要なもの（事前確認）

以下がインストールされていることを確認してください。

ソフトウェア確認コマンド推奨バージョン
Pythonpython --version3.8 以上
pippip --versionPython に同梱
Gitgit --version任意
注意: Python が入っていない場合は python.org からダウンロードしてインストールしてください。

1 スクリプトを取得する

方法A: Git でクローン（推奨）

git clone https://github.com/danalysis707/smec-pdf-downloader.git
cd smec-pdf-downloader

方法B: ZIP でダウンロード

GitHub ページ右上の Code ▼ → Download ZIP を選択し、 展開後にフォルダへ移動してください。

2 必要なライブラリをインストールする

プロジェクトフォルダ内で以下を実行します。

pip install -r requirements.txt

インストールされるライブラリ:

  • requests — HTTP 通信（PDF ダウンロード）
  • pytest — テスト実行用（任意）
仮想環境を使う場合（推奨）: 
python -m venv venv
venv\Scripts\activate   # Windows
pip install -r requirements.txt

3 ダウンロードを実行する

python download.py

実行中は進捗が表示されます。
