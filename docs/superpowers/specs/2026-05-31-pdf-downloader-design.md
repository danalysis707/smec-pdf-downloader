# 中小企業診断士 第1次試験 全科目 PDFダウンローダー 設計書

## 概要

中小企業診断士 第1次試験 全7科目の過去問PDFと解答PDFを、公式サイトから自動ダウンロードするPythonスクリプト。

## 対象

- **科目**: 全7科目（下記）
- **年度**: 令和2〜6年度（直近5年分）
- **取得対象**: 問題PDF・解答PDF の2種類

### 対象科目一覧

| # | 科目名 |
|---|--------|
| 1 | 経済学・経済政策 |
| 2 | 財務・会計 |
| 3 | 企業経営理論 |
| 4 | 運営管理 |
| 5 | 経営法務 |
| 6 | 経営情報システム |
| 7 | 中小企業経営・中小企業政策 |

## ダウンロード元

`jf-cmca.jp`（日本中小企業診断士協会連合会）の公開ページ。

既知のURLパターン（令和3年度解答で確認済み）:
- 解答: `https://www.jf-cmca.jp/attach/test/r{YY}/1j_seikai/{YYYY}{letter}.pdf`
- 問題: 実装時にURLパターンを調査・確定する

※ `{letter}` は科目ごとに異なるアルファベット（a〜g）。実装時に対応表を確定する。

## 使い方

```bash
python download.py
```

## 技術スタック

- **言語**: Python 3.x
- **ライブラリ**: `requests`（HTTPダウンロード）、`pathlib`（フォルダ作成・パス操作）
- **追加インストール**: `pip install requests` のみ

## 動作仕様

1. 令和2〜6年度 × 全7科目 の組み合わせをループ処理
2. 問題PDFのURLを組み立ててGETリクエスト
3. 解答PDFのURLを組み立ててGETリクエスト
4. ダウンロード成功: `downloads/令和X年度/` に保存
5. ダウンロード失敗（404など）: エラーメッセージを表示してスキップ
6. 全処理完了後に結果サマリーを表示（成功/失敗件数）

## 制約・注意事項

- 問題PDFの正確なURLパターンおよび科目とアルファベットの対応表は実装時にサイトを調査して確定する
- 既にダウンロード済みのファイルは上書きしない（再実行しても安全）
- サイトへの負荷を避けるため、ダウンロード間に短いウェイト（1秒）を入れる
